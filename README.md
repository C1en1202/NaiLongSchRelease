## ✨ 功能

- 📅 **课表网格** —— 周次切换、时间冲突检测、点空格直接新建课程、一键分享课表图片
- 🔄 **教务系统一键同步** —— 内嵌登录浙江万里学院教务管理系统（正方 ZFSoft），
  自动拉取整学期课表并合并去重；还会按教务系统的「当前第 N 周」反推开学日期，自动校准周次
- 📄 **PDF 导入** —— 支持教务系统导出的表格版 / 列表版课表，三种解析策略自动择优
- ⏰ **上课提醒** —— 上课前 N 分钟发系统通知：
  「奶龙来提醒你上课啦 · XXX老师的XXX课 XXX前到达XXX教室上课」
- 🎨 **自定义背景** —— 内置默认背景，也可从相册选图，遮罩浓度可调
- 🌙 **今日视图** —— 按时间轴列出今天的课，标出「进行中」

## 📲 安装

1. 进 [Releases](../../releases/latest) 下载 APK
2. 手机上若提示「未知来源」，选择允许后继续安装
3. 包名 `com.nailong.zwu.c1en`

> **覆盖安装不会丢课表** —— 所有版本都用同一把密钥签名，直接装新版本即可。

---

## 🔒 隐私

- 登录完全在学校的统一身份认证页面上完成，App **不读取也不保存任何账号密码**
- 课表只在点「开始抓取课表」时读取一次，不会在后台偷偷拉取
- 所有数据都存在手机本地，不上传任何服务器
